# Հայկ Վ. — վարսավիրի NFC այցեքարտ

Մեկ էջանոց վեբ այցեքարտ՝ NFC քարտի համար (հեռախոսը քարտին հպելիս բացվում է այս էջը)։

## Ինչ կա

- **3D վարսավիրական սյուն** (Three.js)՝ պտտվող պարույր, արույրե գլխիկներ։ Քաշիր՝ ավելի արագ է պտտվում։ Եթե հեռախոսը 3D չի քաշում, մնում է CSS-ով սյունը։
- **«Պահպանել հեռախոսում»**՝ պահում է միայն **անունը, հեռախոսահամարը և կայքի հղումը** (`contact.vcf`)։ iPhone-ում հղումը «կայք» դաշտում է։ Android-ում բացվում է «նոր կոնտակտ» էջը արդեն լրացված, իսկ հղումը մտնում է «Նշումներ» դաշտ (Android-ի այդ պատուհանը կայքի դաշտ չունի)։
- **8 սանրվածք**՝ 3D կարուսել։ «Ամրագրել այս ոճով» → տանում է ամրագրման ձևին՝ ոճն արդեն ընտրված։
- **Ամրագրում**՝ ոճ + օր/ժամ + անուն → պատրաստի **SMS** (նախադիտմամբ, կարելի է պատճենել) և **«Ավելացնել օրացույցում»** (.ics ֆայլ՝ հասցեով և կոորդինատներով, 1 ժամ առաջ հիշեցումով)։ Ժամը «հաստատված» չէ՝ Հայկը պատասխանում է SMS-ով/զանգով։
- **Հասցե և քարտեզ**՝ Սվաճյան 18/3 (40.175586, 44.448884)՝ մութ OpenStreetMap, «Ուղեցույց» (iPhone-ում՝ Apple Maps, մնացածում՝ Google Maps), Waze, Yandex Maps, հասցեի/կոորդինատների պատճենում։
- **Կիսվել այցեքարտով** (հեռախոսի share-ը, եթե չկա՝ պատճենում է հղումը)։
- Ներքևի սահող վահանակ՝ Զանգ · Հասցե · Պահպանել։

## Ինչպես փոխել տվյալները

Բացիր `_src/build.py`, փոխիր `BARBER` (անուն, հասցե, `lat`/`lon`, `instagram`, `hours`, `whatsapp/viber/telegram`), `STYLES` կամ `TEXTS`, հետո՝

```
python -P _src/build.py
```

Ստեղծվում են `index.html` և `contact.vcf`։ Դատարկ դաշտերը էջում չեն երևում։ Հասցեի առաջ քաղաքը գրի `address`-ում, եթե ուզում ես։
`whatsapp: True` միացնելիս ամրագրման ձևում հայտնվում է նաև WhatsApp կոճակ՝ պատրաստի տեքստով (միայն եթե համարի վրա WhatsApp կա)։

## Իրական լուսանկարներ (խորհուրդ)

Նկարազարդումների փոխարեն դիր Հայկի իրական աշխատանքները. `photos/<id>.jpg` (օր.՝ `photos/skin-fade.jpg`, մոտ 600×830 px, ուղղահայաց), հետո rebuild։ id-ները՝ `skin-fade, undercut, pompadour, crew-cut, buzz-cut, quiff, side-part, fade-beard`։

## Տեղադրում և NFC քարտ

1. Էջը պետք է լինի **https** հասցեով (օր.՝ GitHub Pages)։ Բեռնիր `index.html`, `contact.vcf`, `assets/`, `fonts/`, `js/`, `photos/` (`_src/`-ը պետք չէ)։
2. `_src/build.py`-ում `page_url`-ը դիր վերջնական հասցեն (վերջում `/`) և rebuild՝ դա միացնում է հղման նախադիտումը (WhatsApp/Telegram) և Android-ի fallback-ը։
3. NFC Tools → Write → Add a record → URL → հասցեն → Write → հպիր քարտին։

Քարտեզը բեռնվում է OpenStreetMap-ից, երբ այցելուն հասնում է այդ բաժնին (այդ պահին OSM-ը տեսնում է նրա IP-ն). տվյալների խնայողության ռեժիմում՝ միայն հպելիս։
